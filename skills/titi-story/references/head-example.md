# 学习单词提示镜头分解

设计一个儿童有趣的动画视频学习单词提示片。提提像小老师一样，向观众介绍本集单词“头”（国语）、“head”（英文）。开头固定说：“小朋友们，今天学习的单词是……”说中文时只出现“头”，说英文时中文消失，同一位置出现“HEAD”，保持到画面淡出至全黑。文字直接展示在头顶上方，不使用木牌、吊牌或底板。结尾固定说：“LET’S GO!”。总时长8秒。

时间 画面与动作 台词

**0.0–1.0秒**

9:16竖构图，温暖幽暗的森林背景点缀柔和光点。不戴帽版提提面对镜头，中近景，底边裁在短裤下缘或大腿上部，不露膝盖与鞋。头顶文字区域留空。唯一愿望灯固定在自身左前腰，稳定常亮且完整可见，棕色小包在自身右侧。

提提开始说：“小朋友们，今天学习的单词是……”自然延续到下一时段，不在1秒内赶完。

**1.0–3.3秒**

提提说完开场语，轻轻拍拍自己的头。说出“头”的同时，暖金色立体木雕汉字“头”在头顶上方居中出现，边缘柔和发光。片头腰灯稳定常亮，与正片未许愿的灯仅有光源状态不同。

提提：“头。”
画面文字：头

**3.3–4.5秒**

中文消失。提提说英文时，大写“HEAD”在同一位置出现，中文和英文不同屏。

提提：“Head.”
画面文字：HEAD

**4.5–6.0秒**

HEAD继续停留。提提用手轻拍自己的头发，微笑示范，不增加句子字幕，不动腰灯。

提提：“My head.”

**6.0–6.8秒**

构图、比例、裁切不变，HEAD继续显示。提提放下手并招手。

提提：“LET’S GO!”

**6.8–8.0秒**

画面与HEAD一起平稳淡出，轻柔转场音，7.5秒达到全黑，最后0.5秒纯黑。无台词。

# 文字表现建议

头：暖金色木雕汉字，出现时轻轻弹跳，字边缘带柔和暖光。

HEAD：圆润大写英文字母，逐字点亮，字边缘带柔和暖光，出现后停留到最后并和黑屏一起消失。

发音重点：英文读作 /hed/，语速放慢但不要拆成多个音节。

最后一帧必须保持纯黑约0.5秒，方便无缝衔接正式动画。

每个提提出镜画面都只有同一盏愿望灯，固定自身左前腰，完整灯体和挂扣可见，不能手里又出现一盏。灯熄灭时仍在原位，不透明化、不消失。

## 夜景、背景光点与灵活开场

片头、正片、片尾统一夜晚用色：暖色近景、暗色远景。近处人物、树干、苔藓与橄榄绿叶片受柔和蜂蜜金、琥珀暖光照明；远景低亮度、低饱和午夜蓝与墨绿。暖光主要来自两侧低位蘑菇与环境反射，月光只作微弱轮廓补光。避免大片明亮青蓝背景、抢眼大白月盘、阳光束、亮白雾或高亮教学棚景。保留主体自然颜色和柔和高光，不把整个场景染黄。正片未许愿时，暖调不能靠提前亮腰灯提供。

环境微光只表现为细小暖金光点与少量柔焦光斑，稀疏、不规则、远近错落，缓慢漂移；不出现虫身、翅膀、触角或具象卡通飞虫，不围绕人物、不集中头顶、不拖光轨，不遮挡脸、核心道具和教学文字，也不与暗灯腔重叠。教学机位可固定，背景光点与枝叶轻动增加生机；淡出时所有光点一起消失。

第一镜根据当集故事灵活选择道具近景、环境细节、低机位、侧向揭示等，不默认仰望月亮；通过构图、机位和光线变化引出核心词，不更改已确认单集剧情。HEAD夜空是该集选择，不是通用模板。APPLE可用小光点掠过枝叶、显露红苹果的横移近景，不画实体萤火虫。

## 唯一许愿灯：同一模型，仅切换光源

以已确认参考中的许愿灯为唯一模型。锁定高度、宽度、长宽比例、顶盖、透明玻璃灯罩、金属支架、底座、提环、挂扣、材质与自身左前腰的挂放位置。灯与提提的真实尺寸比例恒定，不另设与参考冲突的尺寸；镜头变化时两者按同一透视规律改变画面占比。

灭灯只关闭内部光源，不缩小、压扁、简化、换款，不变成金属罐、小瓶或腰间挂件。透明玻璃及内部灯芯仍存在；灯芯不发光，无火焰、金色亮芯、光晕和向衣物或地面的照明。环境反射可使结构可辨，但不能像灯内已发光。点亮仅让原灯内部发暖金光及局部衣料柔光，不放大、不变形、不重新组装、不把全画面突然提亮。

| 环节 | 光源状态 | 模型 |
|---|---|---|
| 固定问候、教学片头 | 稳定常亮，无需咒语；独立教学片段 | 同一参考灯体 |
| 正片许愿前及咒语未结束 | 完全不亮 | 与亮灯版同尺寸、同结构、同材质 |
| 正片完整咒语结束后 | 首次亮起，随后稳定常亮 | 原灯不变形、不放大 |
| 片尾复读、固定告别 | 稳定常亮，无需重新许愿 | 同一参考灯体 |

正片从独立故事状态开始，不把片头常亮误作正片已经许愿。提提出镜时灯体与挂扣完整可见；自身右侧为包，披风在灯后，手和道具不遮挡。全片唯一，不手持、不复制；提提在画外则灯也在画外。转场只是遮住灯，不表现灯熄灭。

制作前以同一机位、同一尺度建立亮灯／灭灯对照，仅切换光源。验收时排除合理透视变化后比较轮廓、结构与人物比例：暗灯缩小、结构缺失，或亮灯时变大，均不通过；正片许愿前出现亮芯也不通过。逐镜写灯态，不能只在总述写一次。

# 主人公（固定不变）：

提提（TiTi）是浅木色小木偶男孩，棕色层次短发，圆润深色眼睛，温柔好奇的笑容。米色上衣、蓝绿色短裤、蓝绿色叶片斗篷、棕色鞋。棕色小包固定自身右侧；唯一古铜色小愿望灯用短扣固定自身左前腰、灯体落在大腿上段，斗篷放在灯后，不遮挡。全程不戴帽。左手在捡叶后一直持叶，右手邀请、指示或摸头，不移交愿望灯。

# 场景（固定不变）：

夜晚微缩蘑菇森林。开场仰望蓝色天空、明月、星星与树冠，晴朗无雨、无人。之后直接切地面才出现小兔子并开始下雨。地面同一组空间：左侧低矮暖光蘑菇，中间苔藓小路，右侧树干和高处一片宽大叶子。环境光来自月亮与蘑菇，不添加其他提灯。雨轻柔，不打雷。最后雨停，但叶缘仍有积水。

# 质感表现（固定不变）：

细腻木纹、柔软布料、层叠叶片披风、古铜金属灯框、微湿苔藓与圆润蘑菇。小兔子奶白色绒毛，粉色耳内侧。叶脉和水珠清楚，微缩材质可触，暖冷光柔和，不出现强烈能量爆炸。

# 风格：

定格动画（Stop Motion），微距摄影质感，温馨奇幻。正片无文字；全片无背景音乐，只保留人声和特效音效。

# 情节概要：

《谁的头顶在下雨？》：美丽夜空下，小兔子正在欣赏夜晚，突然一滴雨打在头上。它躲到低蘑菇下，却挤得耳朵垂下来。提提发现它需要帮助，低头对腰间关闭的愿望灯说“Little light, shine bright!”。咒语念完，唯一腰灯发出暖金光，光点让树上一片大叶子落到地面。提提捡起叶子给兔子挡雨，兔子走出蘑菇、双耳竖起，头不再淋湿。帮助完成，灯继续稳定常亮至本集结束。雨停了，提提倾斜叶子，一滴叶尖积水却落到自己的头上。兔子指出头上的水滴，提提发现是叶子，两人笑起来。正片独立“Head.”分别落在1-2、3-2、4-3。

# 角色 (Characters)（固定不变）

提提：外形与服饰如上；左前腰灯唯一，右侧包固定；不摘灯。

小兔子：同一只奶白色兔子，体量不随镜头改变。蘑菇下双耳向后垂在身体两侧；完全在蘑菇外时双耳竖起，包括站在叶子下、惊讶和笑时。进入前先垂耳，退出时等两耳完全离开蘑菇边缘才一起竖起，不穿模。

大叶子：同一片宽大深绿色叶子，有一根长叶柄。开始连在右侧高树枝上，没有另一片相同落叶；魔法使其脱落，落地后提提才捡起，不在空中复杂接取。

愿望灯：一个，外形、大小、挂扣和位置全程一致；关闭→念完咒语发暖金光→持续常亮至片尾复读及告别；此规则只适用于正片，独立片头片尾均常亮。关闭状态金属和玻璃仍清楚可见。
