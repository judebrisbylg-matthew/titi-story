# Features

## 固定输出

从学习单词提示镜头分解开始，保留制作模版3.0的18项顺序，详见[输出规范](../skills/titi-story/references/output-format.md)。

## 连贯的正片

4个15秒板块，每板块3张9:16关键帧、分镜表、完整视频提示词和衔接状态。12张组成2行6列、整体16:9大图，外围留白，单格不拉伸不裁切。

## 一词一集

3–6岁、CEFR A1、1个核心词、1–2个教学主句型。正片独立说词3次并留跟读停顿，每镜另有简单英文过渡。画面支持理解，不靠新增字母拼读教学。

## 唯一愿望灯

同一盏小灯固定自身左前腰，右侧包；关闭仍可见。帮助动机明确后念完“Little light, shine bright!”才亮，提供小机会，提提亲自行动，帮助完成后继续常亮，不复制、不手持。

## 完整记录与筛选文稿

固定问候＋8秒提示＋60秒正片＋最多10秒跟读＋固定告别。跟读英文2遍、中文1遍，留两次回应，再温柔提问。问候告别另计。完整英文版保留全部译文；智能文稿仅收录问候、片头1次英文词、正片全部英文、跟读2次英文词与告别。筛选不改变实际口播。

每镜给出运镜设计，正片每段至少一处有动机运动、全片至少三类，与稳镜交替；保留真实比例和完整腰灯，不强制同一景别。

## 制作边界

默认无帽夜景、木偶微缩定格质感；角色与道具比例、站位、持物手和状态连续。正片无文字、全片无音乐，温柔好笑收尾。脚本交付不等于素材生成或成片验收。

[HEAD示例](../skills/titi-story/references/head-example.md)只用于展示格式与具体连续性，兔子、雨、蘑菇和落叶不是通用剧情。

## 最新视觉规则（v2.2.0）

片头片尾腰灯常亮；仅正片许愿前不亮、完整咒语后常亮。亮灭使用同一参考灯体，仅切换内部光源，外形、结构、材质及人物相对比例不变；先验收同机位亮灭对照。全片暖色近景、暗色远景，无大白月盘或明亮蓝雾；背景是稀疏缓慢漂移的柔焦小光点，不是具象萤火虫。每集第一镜按故事灵活设计，不固定仰望天空。详细规则见仓库 skill 与输出规范。
