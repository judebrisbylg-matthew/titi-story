# Workflow

规则以[Skill](../skills/titi-story/SKILL.md)和[输出规范](../skills/titi-story/references/output-format.md)为准；[HTML操作页](../titi-skill-guide.html)提供可视化说明。

## 输入与脚本

1. 提供唯一核心词和中文义；可附人物参考图、帮助对象、故事方向和本集特殊状态。
2. 确定小麻烦、善意、魔法机会、提提行动、结果及轻松反转。没有指定情节可自行创作，已确认的故事不擅自替换。
3. 先规划4个连续15秒板块，再给每段3张9:16关键帧；每张只表现一个瞬间，连续动作另列。
4. 完整稿从学习单词提示开始，保留18项结构。每板块有3行表、完整15秒视频提示词、入段与出段状态。
5. 正片核心词独立出现3次，每次留0.5–1秒响应停顿，每镜有短英文过渡。停顿包含在60秒内。
6. 正片后加10秒内跟读：英文2遍、中文1遍、两次回应空隙及温柔提问。完整台词记录五环节；智能文稿筛成问候、片头1次英文词、正片全部英文、跟读2次英文词、告别。片头中文开场译文、中文词译文、示范句和LET’S GO!不进入智能文稿，实际口播不变。
7. 每镜填写起止构图、运动方向幅度和目的；每段至少一处有动机运动，全片至少三类。词语跟读时稳住，人物道具按真实比例与透视变化。

## 连续性验收

先锁定角色和道具相对大小、屏幕站位、自身左右侧、持物手、环境状态。唯一灯固定自身左前腰，提提出镜时灯体与挂扣可见；正片许愿前关闭，念完“Little light, shine bright!”才亮；许愿后持续常亮至本集结束。不可重复、举起或换手。

HEAD兔耳等单集状态放在该集状态表，不写成所有故事的强制剧情。

## 后续制作（另行执行）

1. 用户确认完整脚本及参考图。
2. 生成并确认2行6列12宫格：单格9:16、整体16:9，外围留白，无裁切拉伸，按行阅读。
3. 提取12张真正的单格图片，核对图号与行列、角色、道具、比例、灯态。不能用整张大图重新取景代替单格提取。导出后核对实际分辨率。
4. 每连续3张确认图配该板块完整提示词，制作一个15秒视频，共4段；检查每段内动作和段间首尾是否衔接。
5. 组合固定问候、8秒教学提示、60秒正片、最多10秒跟读和固定告别；按10秒跟读预算小计78秒，问候告别另计。
6. 实际配音复核0.8倍速起点下的句长、动作和停顿；只用人声与音效，无背景音乐。超时先精简过渡句。
7. 检查竖屏成片后导出，再打开导出文件验收。

状态需分别报告：脚本完成、图片已生成、图片已确认、视频已生成、已导出、已验收。提示词存在不是生成完成，工具完成提示也不是视觉验收。

## v2.2.0 已确认补充

片尾固定引导：“故事看完啦！跟提提再念一遍今天的单词吧！”；10秒内先英文两遍（各留1秒回应），再中文一遍，最后“你学会了吗？”。片尾必须附固定四行文字表现建议，详见输出规范。片头片尾独立教学灯常亮；只有正片许愿前灯不亮、完整咒语后常亮；全程同一灯体仅切换光源。正片第四段13.5–14.5秒圆形收幕归零，14.5–15秒用不透明纯黑素材替换末尾0.5秒；导出尾帧不得残留小孔或灯光，不延长60秒正片。

## 最新视觉规则（v2.2.0）

片头片尾腰灯常亮；仅正片许愿前不亮、完整咒语后常亮。亮灭使用同一参考灯体，仅切换内部光源，外形、结构、材质及人物相对比例不变；先验收同机位亮灭对照。全片暖色近景、暗色远景，无大白月盘或明亮蓝雾；背景是稀疏缓慢漂移的柔焦小光点，不是具象萤火虫。每集第一镜按故事灵活设计，不固定仰望天空。详细规则见仓库 skill 与输出规范。
