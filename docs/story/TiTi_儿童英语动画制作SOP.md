# TiTi 儿童英语动画制作 SOP

## 1. 项目目标

用固定原创角色 `提提 TiTi`，持续制作适合儿童英语启蒙的短动画。

内容目标：
- 面向低龄儿童英语磨耳朵
- 英语表达简单、重复、易模仿
- 以画面帮助理解，不依赖复杂对白
- 每集只讲一个小情境、一个小情绪、一个小收获
- 适合批量化、系列化生产

## 2. 角色总设定

主角：`提提 / TiTi`

角色定位：
- 温和、好奇、勇敢
- 愿意观察、帮助、表达
- 适合作为儿童进入故事世界的“陪伴型主角”

角色固定识别点：
- 木偶质感小男孩
- 圆润五官，黑色圆眼，表情亲和
- 蓝绿色系服装
- 叶片感披肩/斗篷
- 小包
- 腰侧小提灯
- 整体为自然、童话、森林系气质

## 3. 角色出镜规则

这是后续所有制作的硬规则，优先级高于单集创意。

### 3.1 日夜版本规则

- 默认全程夜景、不戴帽版提提；教学提示使用固定无帽夜景模板。
- 用户明确指定白天或其他角色版本时，按其确认参考图锁定，不自动换帽。

### 3.2 角色一致性规则

任何单集制作中，不可轻易改动以下内容：
- 脸型和五官比例
- 木纹材质表现
- 主服装配色
- 叶片披肩结构
- 小包位置
- 小提灯位置与体量

可变化内容：
- 表情
- 手势
- 站姿和动作
- 斗篷摆动
- 光线氛围
- 场景道具

### 3.3 提灯规则

- 提灯始终为 `小尺寸`
- 全集唯一一盏，固定自身左前腰，同一短扣挂在腰带；棕色包在自身右侧
- 不放大成主视觉主体
- 不拿起、不托举、不复制；需要施法时只低头对腰灯说话
- 提提出镜时灯体与挂扣完整可见；关闭不等于消失，环境光照见金属和玻璃

## 4. 愿望灯设定

提提腰间的小提灯，正式设定为：

`愿望灯`

一句话设定：

`提提真心想帮助别人，念完“Little light, shine bright!”后，唯一腰灯才亮起，提供小机会；提提亲自行动，许愿后灯持续常亮至本集告别结束。`

### 4.1 触发规则

愿望灯只有在以下条件同时成立时，才会发亮：

1. 提提的愿望是发自真心的
2. 愿望的目的，是帮助别人
3. 愿望本身是善良的、温暖的
4. 提提愿意亲自行动，而不是只想靠魔法解决一切
5. 完整念完固定咒语“Little light, shine bright!”后才发暖金光；教学提示灯常亮；仅正片未触发时关闭内部光源

### 4.2 愿望灯能做什么

愿望灯适合实现“小而温暖的小奇迹”，例如：

- 帮迷路的小动物找到方向
- 让黑暗的小路亮一点
- 让受伤的小花重新挺起来
- 让掉落的小东西被发现
- 让寒冷的角落变暖一点
- 让难过的人重新露出笑容
- 给提提一个帮助别人的提示

### 4.3 愿望灯不能做什么

它不能：

- 伤害别人
- 实现自私、贪心、恶意的愿望
- 无条件满足提提自己的私欲
- 凭空变出夸张的大型物品
- 一下子解决整个世界的大问题
- 替提提完全做完所有事情

### 4.4 最重要的限制

愿望灯不会直接替提提完成一切。

它只会：

- 发出提示
- 提供一点小魔法
- 创造一个帮助别人的机会

但最后，事情仍然需要提提自己去做。

### 4.5 视觉表现

愿望灯发亮时的视觉语言应保持：

- 微光亮起
- 暖金色发光
- 柔和闪烁
- 像呼吸一样明暗变化
- 轻轻带动周围空气、叶片或微尘

不做成：

- 爆炸式闪光
- 战斗型法术
- 巨大能量冲击
- 夸张破坏效果

## 5. 内容选题标准

每一集只做一个儿童可快速理解的小主题。

优先选题方向：
- 打招呼
- 找东西
- 帮助朋友
- 分享食物
- 认识颜色
- 认识大小
- 认识方位
- 天气变化
- 白天与夜晚
- 出发与回家
- 害怕与勇敢
- 等待与发现

选题筛选标准：
- 每镜可用简单英语承接，正片核心词独立说出3次并留停顿；不把总台词限制为3到8句
- 能拆成清晰动作
- 能用画面直接表现
- 适合儿童模仿重复
- 有温和情绪起伏，但不过度复杂
- 能自然接入愿望灯亮起的帮助动机

## 6. 单集标准结构

教学提示8秒，正片4个15秒板块共60秒，片尾跟读最多10秒。按10秒跟读预算小计78秒，固定问候与固定告别另计。

实际播放顺序：Hello, I’m TiTi! → 教学提示 → 正片 → 片尾跟读 → Bye-bye. See you next time!

推荐结构：

1. 开场建立情境
- 交代时间、地点、状态，可先用无人环境空镜
- 人物按剧情需要再出现，不强制开场直接出现提提

2. 出现一个小目标
- 想找什么
- 想去哪里
- 想帮助谁
- 想解决什么小问题

3. 愿望触发
- 提提发现有人需要帮助
- 提提产生善良愿望，低头向腰灯念完“Little light, shine bright!”
- 同一腰灯才亮起，完成帮助后持续常亮

4. 过程推进
- 得到一点提示或小魔法
- 提提亲自行动
- 遇到一点小困难
- 再尝试

5. 结果解决
- 问题被解决
- 对方得到帮助

6. 收尾反转
- 重复核心英语
- 在最后加入一个儿童能立刻看懂的反转
- 反转必须是轻松、搞笑、逗小朋友开心的

## 7. 英文脚本标准

英语等级目标：
- 以 `CEFR A1 / 启蒙级` 为主

句子标准：
- 单句尽量短
- 多用主谓宾直述句
- 高频词优先
- 重复核心词和核心句式
- 尽量避免从句、抽象修辞、复杂时态

适合的句式：
- This is ...
- I see ...
- Where is ...?
- Here it is.
- I can ...
- Let’s ...
- Help ...
- The light is ...
- Good morning.
- Good night.
- Thank you.

脚本规则：
- 每集只保留 `1 个核心词`
- 每集只保留 `1 到 2 个核心句型`
- 中英文含义必须对应
- 英文要能被画面验证
- 结尾必须包含一个 `搞笑反转`
- 愿望灯的触发必须和“帮助别人”的动机一致

## 8. 分镜标准

正片4个15秒板块，每段3张9:16关键帧。大图2行6列、整体16:9，先上排后下排阅读，每连续3格为一段。单格不拉伸不裁切，以外围留白补足比例。

每板块用3行表格，区分单一瞬间的关键画面与连续动作；表后附完整15秒视频提示词与入段、出段衔接状态。每个镜头需要明确写出：
- 镜头编号
- 时长
- 景别
- 画面内容
- 提提动作
- 表情
- 关键道具
- 英文台词，每镜都有简短过渡，核心词独立出现共3次并留0.5–1秒停顿
- 中文含义仅作制作对照，不配进英文正片
- 音效/氛围

音频规则：
- `不要使用背景音乐`
- `只保留人声和特效音效`
- 音效用于辅助动作、情绪、愿望灯亮起和反转节奏

推荐镜头风格：
- 动作清楚
- 焦点明确
- 背景不过乱
- 每镜写运镜起止、方向幅度与目的；正片每段至少一处有动机运动、全片至少三类，与稳镜交替
- 推拉改变画面占比但不改变真实相对体量；镜内保留完整腰灯
- 少炫技转场
- 让儿童一眼看懂“谁在做什么”

## 9. 画面生成标准

### 9.1 固定视觉方向

- 童话森林感
- 温暖自然材质
- 木偶角色质感稳定
- 光线柔和
- 画面干净
- 色彩统一，不要杂乱跳色

### 9.2 场景与角色调用规则

- 默认夜景调用不戴帽版提提；用户明确变更时用其确认版本，片内保持一致

### 9.3 一致性检查

每次出图后都要检查：
- 角色是不是提提
- 日夜版本是否调用正确
- 提灯大小是否正确
- 提灯是否唯一、在自身左前腰、挂扣可见、关闭后仍在
- 角色道具相对大小、持物手、左右站位与跨段状态是否一致
- 愿望灯发光方式是否柔和、稳定
- 服装有没有漂
- 脸部比例有没有漂
- 风格是否偏离既定世界观

## 10. 标准制作流程

### 第一步：确定单集主题

输出内容：
- 本集主题
- 核心词
- 核心句型
- 情绪目标
- 反转设计
- 愿望灯触发点

### 第二步：生成简版故事

输出内容：
- 中文故事梗概
- 英文简版台词
- 每句对应含义

要求：
- 情节简单
- 能被拆镜头
- 能被儿童跟读
- 结尾要留给搞笑反转
- 愿望灯必须服务于“帮助别人”

### 第三步：拆分镜头

输出内容：
- 完整分镜表
- 每镜头时长
- 角色动作
- 场景说明
- 台词落点

### 第四步：生成关键画面

确认脚本与参考图后，生成并核对2行6列大图；再提取12张单格竖图，逐张检查图号、比例、道具、灯态和分辨率。每连续3张确认图配本段提示词制作15秒视频，共4段。不要把整张大图重新取景当成单格提取。

### 第五步：整理视频制作素材

每集至少整理以下内容：
- 角色图
- 场景图
- 分镜表
- 中英台词表
- 配音文案
- 特效音效建议
- 封面图

### 第六步：配音与节奏校对

检查重点：
- 英语语速是否适合儿童
- 停顿是否清楚
- 关键词是否听得清
- 画面切换是否跟得上句子
- 是否完全没有背景音乐
- 愿望灯亮起是否有清楚的音效标识
- 特效音效是否足够支撑搞笑反转

### 第七步：发布前复核

发布前必须过一遍以下检查：
- 主角是不是提提
- 日夜帽子规则是否正确
- 英文是否足够简单
- 中文是否准确
- 剧情是否一眼能懂
- 镜头是否干净
- 风格是否统一
- 愿望灯规则是否被遵守
- 结尾是否有搞笑反转
- 是否无背景音乐
- 是否适合做系列延展

## 12. 系列化建议

适合提提的长期系列：
- 提提的一天
- 提提去森林里
- 提提帮助朋友
- 提提发现新东西
- 提提学会表达
- 提提的白天和夜晚
- 提提和愿望灯

建议的生产顺序：
1. 先做 `10 集基础启蒙`
2. 再做 `10 集情绪表达`
3. 再做 `10 集简单互动故事`

## 13. 当前项目最终规则

从现在开始，项目统一以这套规则为准：

- 主角名称固定为 `提提 / TiTi`
- 只使用当前定稿角色
- 默认全程夜景、不戴帽版；用户明确变更时锁定其确认参考图
- 小提灯正式名称为 `愿望灯`
- 愿望灯只响应善良愿望
- 愿望灯只能用于帮助别人
- 愿望灯不能成为万能外挂
- 愿望灯只提供机会，最终仍然需要提提行动
- 提灯为小尺寸腰挂道具
- 每集只保留 `1 个核心词`
- 教学提示8秒＋正片4×15秒＋片尾跟读最多10秒；问候与告别另计
- 结尾必须有 `搞笑反转`
- 音频只保留人声与特效音效，不要背景音乐
- 所有内容服务于儿童英语磨耳朵
- 所有故事都优先简单、温暖、可重复、可系列化

## v2.2.0 已确认补充

片尾固定引导：“故事看完啦！跟提提再念一遍今天的单词吧！”；10秒内先英文两遍（各留1秒回应），再中文一遍，最后“你学会了吗？”。片尾必须附固定四行文字表现建议，详见输出规范。片头片尾独立教学灯常亮；只有正片许愿前灯不亮、完整咒语后常亮；全程同一灯体仅切换光源。正片第四段13.5–14.5秒圆形收幕归零，14.5–15秒用不透明纯黑素材替换末尾0.5秒；导出尾帧不得残留小孔或灯光，不延长60秒正片。

## 最新视觉规则（v2.2.0）

片头片尾腰灯常亮；仅正片许愿前不亮、完整咒语后常亮。亮灭使用同一参考灯体，仅切换内部光源，外形、结构、材质及人物相对比例不变；先验收同机位亮灭对照。全片暖色近景、暗色远景，无大白月盘或明亮蓝雾；背景是稀疏缓慢漂移的柔焦小光点，不是具象萤火虫。每集第一镜按故事灵活设计，不固定仰望天空。详细规则见仓库 skill 与输出规范。
