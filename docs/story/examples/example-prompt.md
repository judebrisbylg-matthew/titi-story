# Example Prompt

最简请求：

```text
Use $titi-story to write a complete TiTi story for BAG（包）.
```

带故事方向：

```text
请使用titi-story，为BAG（包）写一集：朋友用小包带松果回家。
保留无帽版夜景提提、唯一腰灯和固定咒语，不套用兔子躲雨情节。
从学习单词提示镜头分解开始输出完整稿。
正片4个15秒板块，每段3张9:16分镜＋完整视频提示词＋衔接状态。
12宫格为2行6列、整体16:9，用外围留白保持单格比例。
正片独立说词3次并留停顿，每镜配简短英文过渡。
正片分镜增加有动机的缓推、缓拉、横移/跟拍和轻摇，比例与腰灯不漂移。
正片后新增10秒内跟读：英文2遍、中文1遍、两次回应与温柔提问。
完整台词记录五环节；智能文稿只留问候、片头1次英文词、正片全部英文、跟读2次英文词和告别。
问候告别另计时长；仅提供脚本，不生成或发布素材。
```

局部修订：

```text
只调整正片第二板块的动作衔接，其他情节与板块保持不变；同步更新受影响的台词汇总。
```

用户明确要求结构变更时按新要求执行，不能用默认模板拒绝修改；不要把一次情节偏好默认为永久规则。通用输入字段见[模板](../templates/story-brief-template.md)。
