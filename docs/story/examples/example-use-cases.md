# Example Use Cases

## 1. Episode Generation

Generate one new standard episode from a core word:

```text
Use $titi-story to write a new TiTi story for the core word HOME.
```

## 2. Night Story With Lantern Logic

```text
Use $titi-story to write a new TiTi story for the core word LIGHT.
Make it happen at night and make the wish lantern help a lost little friend.
```

## 3. Series Planning Support

```text
Use $titi-story to write episode 3 for the core word RAIN.
Keep the format identical to the existing TiTi production template.
```

## 4. Template Compliance Check

```text
Use $titi-story and do not change the section order.
Write a new TiTi story for the core word APPLE.
```

## 5. Production Handoff Draft

```text
Use $titi-story to write a production-ready TiTi story for the core word PATH.
Keep it easy to visualize and suitable for image prompting and dubbing.
```
